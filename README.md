# Baker420 California

A production-ready marketing website for **Baker420 California** — a California medical marijuana card evaluation service connecting California residents with licensed physicians for online MMJ recommendations.

## Stack

- Next.js 16 (App Router, TypeScript)
- React 19
- Tailwind CSS v4 (with `@tailwindcss/postcss`)
- react-hook-form 7 + zod 4
- lucide-react icons
- Inter + Playfair Display via `next/font`

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run start` — start the production server
- `npm run lint` — lint the codebase

## Brand

- Sunset orange `#C2410C`, golden poppy `#FACC15`, Pacific deep blue `#1E3A8A`, warm cream `#FFFBF5`.
- Headings: Playfair Display. Body: Inter.

## Legal Framework

This site references California's Compassionate Use Act of 1996 (Prop 215), SB 420 (2003), and the CDPH Medical Marijuana Identification Card (MMIC) program. Evaluations are conducted by California-licensed physicians.
